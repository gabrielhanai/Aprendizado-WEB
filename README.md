# Aprendendo

Projeto educacional dedicado ao estudo e prática de desenvolvimento web frontend com foco em HTML, CSS e JavaScript.

## Propósito

Este projeto serve como espaço de aprendizado contínuo para consolidar conhecimentos em tecnologias web, explorando conceitos fundamentais e práticas recomendadas de desenvolvimento frontend e backend. O objetivo é aprender através da prática, implementando soluções reais e compreendendo todos os mecanismos por trás.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

O projeto é organizado em um menu central que fornece acesso a diversos módulos de aplicação, cada um explorando diferentes aspectos do desenvolvimento web.

## Como Usar

Abra o arquivo `index.html` em um navegador web moderno para acessar a aplicação ou acesse a partir desse link hospedado no github pages: https://gabrielhanai.github.io/Aprendizado-WEB/

## Notas

Este é um projeto em desenvolvimento contínuo, destinado exclusivamente a fins educacionais e de aprendizado.
